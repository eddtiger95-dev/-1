# Asia Price Scanner — как получить APK и пользоваться

## 1. Сборка APK (один раз, без Android Studio)
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (Private).
2. Загрузите в него ВСЁ содержимое этой папки, включая скрытую папку `.github`
   (на компьютере: Add file → Upload files → перетащить папку целиком).
3. Откройте вкладку **Actions** → **Build APK**. Сборка стартует сама, занимает 3–6 минут.
   Если не стартовала: Run workflow.
4. Когда появится зелёная галочка, откройте запуск и внизу скачайте **AsiaPriceScanner-apk**
   (это zip, внутри `app-debug.apk`).
5. Распакуйте, перенесите APK на POCO X7 Pro и установите
   (разрешите «Установку из неизвестных источников» для файлового менеджера).

Если сборка красная — откройте её лог, скопируйте текст ошибки и пришлите мне.

## 2. Включение доступности
Настройки → Специальные возможности → Установленные службы → **Asia Price Scanner** → Включить.
На HyperOS при блокировке («Ограниченные настройки»): Настройки → Приложения → Asia Price Scanner →
три точки справа вверху → «Разрешить ограниченные настройки», затем включить службу.
Также отключите для приложения экономию батареи (Настройки → Приложения → Asia Price Scanner → Контроль активности → Нет ограничений).

## 3. Работа
1. «Выбрать Excel» → файл с QR в столбце D.
2. Включите/выключите «Искать по коду из QR» (по умолчанию поиск по названию).
3. «Начать». Приложение откроет «Азию», введёт запрос в поиск, откроет карточку и запишет цены.
4. После обработки: «Скачать готовый Excel» (Asia_Prices_дд-мм-гггг.xlsx).
   Цена → столбец B, «С приложением» → столбец E, столбец C не меняется, картинки удалены.

Результаты хранятся в базе после каждого товара; при закрытии приложения прогресс не теряется.

## 4. Диагностика (важно для первой настройки)
Мой код не видел экранов «Азии», поэтому первый запуск, скорее всего, потребует подстройки.
- «Снять дамп экрана»: нажмите, за 8 секунд откройте «Азию» на нужном экране (главная, поиск, карточка товара).
  Файл `Загрузки/asia_dump.txt` пришлите мне.
- «Сохранить лог ошибок»: файл `Загрузки/asia_errors.log` — тоже пришлите.

## Ограничения версии 1.0
- Камера «Азии» не используется: подмена камеры без Root на Android невозможна. Вместо сканирования QR идёт поиск.
- Картинки в Excel: поддерживаются обычные и «изображение в ячейке». Если QR не найдены, приложение скажет об этом.
- Возврат в наше приложение происходит в конце (или по паузе/стопу), а не после каждого товара.
